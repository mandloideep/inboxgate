# Support

InboxGate is pre-release community software and does not provide a service-level agreement.

Use [GitHub Discussions](https://github.com/mandloideep/inboxgate/discussions) for usage questions, design discussion, and general help.
Use the issue forms for reproducible bugs and approved change proposals.
Search existing discussions, issues, and documentation before opening a new thread.

Never post credentials, OAuth tokens, email content, account identifiers, private domains, or production URLs.
Report suspected vulnerabilities privately according to [SECURITY.md](SECURITY.md).
